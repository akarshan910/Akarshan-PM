The rules
01Your order, everywhere. Drag projects in Studio (or use ↑ ↓). Volume numbers follow the order; links use each project’s address, so reordering never breaks a shared link.
02The homepage is a cap, not a list. Each shelf shows its lead card plus one, two or three rows of three. Past the cap, the last cell turns into “See all N”; a gap in the last row gets an “All work” tile. Phones show the same projects.
03The work page carries the rest. It holds every published project in a compact list, with filters, search, sort and 24 at a time. Past a hundred rows it virtualises, so it stays fast.
04Shelves are yours too. Add a shelf (for example “Side projects”), rename one, reorder shelves, or turn one off. A shelf with nothing published hides itself.
05Lead card per shelf. The first published project opens each shelf as a large card. Drag another to the top, or star it in Studio.
06Light by default. The homepage loads only the covers it shows. Covers further down the work page load as you scroll.
07Phones get a list, not a rail. Each shelf shows its lead card, then compact rows, capped like the laptop shelf. Nothing hides off to the side. The work page stays a list, with filters in a bottom sheet.

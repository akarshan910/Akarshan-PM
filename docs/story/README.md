# The story of this portfolio

This folder records how the portfolio evolved: from a single hard-coded page into a designed site run by its own CMS. It covers what was decided along the way and why.

It exists for two reasons:

1. **The portfolio is part of the portfolio.** How a product manager frames a problem, explores options, decides, and writes it down is the work. This repository shows that process on a real product: this one.
2. **It's the source for the project wiki.** The wiki gets written after the build is complete, so it can document what was actually built. The reasoning behind it is easy to lose by then, so it's captured here as it happens.

| Document | What's in it |
| --- | --- |
| [01 · Evolution](01-evolution.md) | The timeline: version 1, the audit, three design rounds, the platform design, every round of feedback, and V0 |
| [02 · Decisions](02-decisions.md) | Each significant decision: context, options, the choice and its trade-offs |
| [03 · Wiki plan](03-wiki-plan.md) | The wiki's pages, what each one must cover, and when to write it |

**Keep it current.** During the build, add entries to 01 and 02 whenever something significant changes:

- a decision is revised;
- a trade-off turns out differently than expected;
- the owner gives feedback that changes the product.

The engineering handover's last milestone turns these notes into the wiki.
